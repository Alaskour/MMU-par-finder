
# MMU link-parser

 Это приложение ускоряет получение нужной информации и позволяет автоматизировать получение информации, необходимой для учебы в университете ММУ.



## Installation

Скачайте исходные файлы проекта, затем загрузите необходимые библиотеки:

```bash
  npm install
```
    
Также для прохождения авторизации необходимо создать файл .env.mmu и указать в нем логин и пароль
```env
  LOGIN="REPLACE THIS"
  PASSWORD="REPLACE THIS"
```
